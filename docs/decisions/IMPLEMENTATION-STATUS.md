- 病例按创建医生隔离，管理员和患者不能通过医生接口读取病例；
- 一次性邀请码只保存摘要，患者会话凭证只保存摘要；
- 患者设备会话兑换、医生启动、患者安全暂停、医生恢复和结束；
- 医生启动会话前必须确认当面知情同意，保存医生、时间和版本；
- 病例归档立即结束会话，并从归档时间起计算 30 天删除期限；
- 写接口幂等键校验、统一错误响应和脱敏审计事件；
- 医生工作台、病例详情、邀请码管理及患者实时会话页面接入真实 API；
- Q1–Q8 Prompt 门控、情绪最多六项和核心领域状态转换测试。
- Q1–Q8 逐题保存、刷新恢复、完整度校验和首轮无风险分级口径；
- 声音特征到九项视觉特征的确定性映射、自动柔化和医生受控确认；
- 三组可重复生成的去标识化示例病例，覆盖完整、等待和待兑换状态。
- 后端风险规则表和 `RISK-V1.0` 判定引擎，支持直接命中、上下文排除、PII 格式检测与失败关闭；
- 风险拦截不保存患者原文，只记录规则版本和脱敏规则编码；
- 危机表达命中后自动进入安全暂停，只有现场医生可以恢复会话；
- 患者调整原文加密保存，仅当前监督医生可见，患者接口只返回状态；
- 每病例终身最多三次调整，风险通过创建请求即消耗，幂等重放不重复消耗；
- 医生可原样接受、选择受控指令后接受或拒绝，患者原文永不直接进入模型；
- Mock Avatar 版本和会话授权骨架，患者端与医生审核端已接入真实 API；
- 示例数据增加一条授权记录和待审核调整，覆盖风险、审核、额度与权限的自动化测试。
- 独立管理员登录和后台页面，覆盖医生账户审批、拒绝、启停及现有登录撤销；
- 管理员风险规则维护，强制更新规则版本且只作用于后续新请求；
- 聚合统计与白名单脱敏审计，管理员接口不返回研究编号或病例内容；
- 归档病例最小化列表与到期前恢复，旧患者会话不恢复且原删除时间固定不变；
- `retention_jobs`、Celery Worker/Beat 和每小时到期扫描；
- 到期永久删除病例、会话、邀请码、Q1–Q8、视觉特征、Avatar 版本、授权、调整、审计和幂等数据；
- 删除依赖失败自动重试三次，失败状态和脱敏错误代码可供管理员查看；
- 删除完成后病例外键解除，只保留不可逆摘要和各类别删除计数。
- 供应商无关的 Avatar 生成状态机，覆盖排队、生成、检查、医生复核、通过、拒绝和失败；
- GPT Image 2 适配器，固定 1024×1024 PNG、`moderation=auto`、中等质量和 180 秒超时；
- 完整 Prompt 不落库，只保存模板版本和 SHA-256 摘要，患者原始调整文本不进入模型；
- Mock Provider 与正式 Provider 共享同一任务、审核和授权链路，无 API Key 时可安全联调；
- MinIO/S3 兼容对象存储、15 分钟签名图片 URL，以及 30 天删除任务中的对象前缀清理；
- 医生首版生成、相同特征重生成、患者受控调整生成、图片审核、会话授权和历史版本回退；
- 患者端只展示医生已审核并授权的版本，未授权候选图不能通过患者接口读取；
- GPT Image 2 输出后的 PNG 签名、体积和 1024×1024 尺寸失败关闭检查；
- 图片结构安全检查失败最多自动重新生成一次，第二次失败时关闭放行；
- 图片审核与患者授权拆分为两个独立门禁，审核通过不会自动向患者展示；
- 历史版本回退会撤销病例现行授权、重新进入医生审核，并要求再次明确授权；
- 新生成版本冻结 Q1–Q8 和视觉特征快照，不受后续表单修改影响；
- 医生指定版本下载包只包含 PNG 和对应 Q1–Q8 JSON，并记录脱敏下载审计；
- 医生账户申请、本地开发邮箱验证、管理员审批和审批后登录闭环；
- 就绪检查真实探测 PostgreSQL、Redis、对象存储和图片 Provider 配置，不再返回占位状态；
- 医生可查看单个版本完整快照，并可显式撤销当前患者展示授权；
- 生产模式拒绝本地密钥、SQLite、Mock Provider、示例数据、HTTP 前端源和公开 API 文档等不安全配置；
- 网关增加防嗅探、防嵌入、最小化 Referrer、设备权限和跨窗口隔离响应头；
