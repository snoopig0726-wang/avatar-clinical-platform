# 实现状态

更新时间：2026-07-30

## 已完成

### 账户、权限与病例

- FastAPI、React、SQLAlchemy、Alembic、Celery 和容器工程骨架；
- 医生账户申请、邮箱验证、管理员审批、登录、停用和现有会话撤销；
- 医生、患者、管理员三类角色由后端执行权限隔离；
- 病例按创建医生隔离，管理员和患者不能通过医生接口读取病例；
- 一次性邀请码与患者会话凭证只保存摘要，并绑定当前受监督会话；
- 医生启动会话前必须确认现场知情同意；
- 患者安全暂停、医生恢复、医生结束会话及结束后的患者提示；
- 病例归档、30 天留存、管理员恢复和到期永久删除。

### Q1–Q8 与视觉映射

- Q1–Q8 逐题保存、刷新恢复、必填和可选字段校验；
- 六种固定情绪最多选择六项，最终画面最多呈现两组局部面部信号；
- 首轮结构化 Q1–Q8 不执行患者调整文本风险分类；
- 声音特征到九项视觉特征的确定性映射；
- 儿童、老年、高强大感和高恶意感组合的低刺激安全等价转换；
- 医生可以在九项受控维度内检查、恢复、修改并确认视觉特征；
- 每次生图保存对应 Q1–Q8、视觉特征和来源视觉特征 ID 的不可变快照；
- 同一病例创建新会话并重新录入 Q1–Q8 后，只以本次新视觉特征判断是否已经生图。

### GPT Image 2

- 当前图像生成 Provider 为 OpenAI，模型为 `gpt-image-2`；
- 固定生成 1024×1024 PNG，默认 `quality=low`、`moderation=auto`、单次 1 张、180 秒超时；
- Prompt 模板版本为 `voice-to-appearance-v1.1`；
- 完整 Prompt 不落库，只保存模板版本与 SHA-256 摘要；
- 支持首版生成、同特征重新生成、特征更新生成和患者受控调整生成；
- 医生可以在视觉特征确认页直接发起生图；
- 患者在医生生图和审核期间看到实时等待进度；
- 图片返回后执行 PNG 签名、体积、格式和 1024×1024 尺寸检查；
- 图片安全检查、医生人工审核和患者会话授权是三个独立门禁；
- 未审核、未授权或失败候选图不会向患者展示，也不会覆盖原已授权版本；
- 历史版本回退会撤销现行授权，并要求重新审核和再次授权；
- 医生可下载指定已审核版本，下载包仅包含 PNG 与对应 Q1–Q8 JSON；
- 已归档病例的图片版本只保留下载和删除操作。

### 患者调整与多语言风险

- 每次患者会话拥有独立的 3 次调整额度；
- 新邀请码兑换形成新会话，新会话额度从 0/3 重新开始；
- 风险校验通过且成功创建调整请求时消耗额度；
- 风险拦截、服务异常、会话无效或未创建请求时不消耗额度；
- 同一病例同时只允许一条待审核、已批准待生成或生成中的患者调整；
- 患者原文加密保存，仅当前监督医生可见，不直接进入 GPT Image 2；
- 医生可以直接接受系统研判、可选重写患者描述后重新映射，或填写理由拒绝；
- 医生重写文本必须重新经过风险检查，最终只使用后端映射的低刺激受控指令；
- `RISK-V1.3` 覆盖 11 类规则，并支持简体中文、繁体中文和英文；
- 风险规则支持直接命中、上下文条件、刀具/创口与血液的跨分隔符组合匹配、安全否定语境、PII 格式检测和失败关闭；
- 危机表达命中后自动暂停当前会话，只有医生可以恢复；
- 患者满意当前图片后，医生端显示“已生成图片”并收到短时提示。

### 数据、审计与运维

- 患者调整原文和医生重写原文均使用应用层加密；
- 普通日志和审计日志不保存患者原文、完整 Prompt、图片内容或邀请码明文；
- 关键写操作使用 PostgreSQL 行锁和幂等键保护；
- 登录、申请、邮箱验证、邀请码兑换和调整提交使用 Redis 匿名摘要限流；
- MinIO/S3 兼容对象存储、短期签名 URL 和到期对象删除；
- 管理员只能读取聚合统计、规则配置、运行告警和脱敏审计；
- Celery Worker/Beat 执行生成任务、重试和每小时留存扫描；
- GitHub Actions 覆盖后端测试、前端构建和浏览器流程。
