# Q1–Q8 声音到外貌特征：一步生图 Prompt

版本：`voice-to-appearance-v1.1`
交付对象：后端 / AI 接入开发

本文件是 Q1–Q8 声音到外观映射的文本规范。运行时实现必须与本文件保持同版本；测试输入以 `prompt_mapping_test_cases.json` 为准，不得修改测试表单值来提高分数。

> 项目兼容说明：当前产品保留已确认的 Q6 六项固定情绪多选能力，但渲染时仍严格执行
> v1.1“最多两组局部面部信号”的限制，其余情绪只作为相容的轻度气质。运行时还保留
> “受控转换 → 医生确认最终视觉特征 → 生图”的门禁；风险判断在进入 Prompt 构建前完成，
> 不把风险原文传给图像模型。

---

## 1. 目标与边界

根据医生端录入的匿名结构化声音特征，生成单人、虚构、非身份化、低刺激的人类写实头像。声音只能映射为受控的脸型比例、局部表情、质感、光影和构图；不得推断或生成真实身份、种族、职业、诊断、人格结论或患者本人样貌。

目标输出：

- 1024×1024、1:1 PNG；图像接口的 `size` 同样固定为 `1024x1024`；
- 正面或不超过 15° 的轻微侧脸，眼平、居中、单人胸像；
- 浅暖灰或医疗纸白纯色背景，柔和均匀漫射光；
- 米白、浅灰或浅雾蓝的纯色上衣，无首饰、文字、logo、水印或场景叙事。

低刺激与安全不等于抹除特征：每个已填写字段都必须留下一项可见、克制且安全的视觉信号。

---

## 2. 输入契约

```json
{
  "voice_gender": "male",
  "age_sense": "young",
  "pitch_level": 3,
  "speaking_rate_level": null,
  "timbre": null,
  "emotions": ["sadness"],
  "power_level": null,
  "malice_level": null,
  "risk_level": "normal",
  "doctor_overrides": {},
  "generation_mode": "initial"
}
```

| 字段 | 规则 |
|---|---|
| `voice_gender` | 必填：`male` / `female` / `uncertain_mixed` |
| `age_sense` | 必填：`child` / `adolescent` / `young` / `middle_aged` / `elderly` / `uncertain` |
| `pitch_level` | 必填：整数 1–5 |
| `speaking_rate_level` | 可选：整数 1–5；为空时不添加语速专属信号 |
| `timbre` | 可选单选：见下表 |
| `emotions` | 必填：固定枚举，项目兼容层允许多选最多 6 项；视觉蓝图最多呈现两组面部信号 |
| `power_level` / `malice_level` | 可选：整数 1–5；为空时内部使用 3 档中性基线，不视为医生明确观察事实 |
| `risk_level` | 必填：`normal` / `sensitive` / `crisis` / `high_stimulus` |
| `doctor_overrides` | 可选，仅能覆盖规定视觉维度，不能突破安全边界 |

音色：`hoarse_rough` 沙哑粗糙、`clear_transparent` 清亮通透、`sharp_piercing` 尖锐刺耳、`low_rich` 低沉浑厚、`breathy_weak` 气声虚弱、`nasal` 鼻音偏重、`mumbled` 口齿含糊、`heavy_accent` 厚重口音、`fine_soft` 纤细轻柔。

情绪：`anger` 愤怒、`indifference` 冷漠、`sarcasm` 嘲讽、`sadness` 悲伤、`fear` 恐惧、`commanding` 命令式。

## 3. 风险门禁

风险判断必须在调用图片模型之前完成。

| 风险等级 | 行为 |
|---|---|
| `normal` | 允许生成，执行完整映射和永久禁止项 |
| `sensitive` | 允许生成，降低对比度、阴影、冷调和负面神态强度，但保留安全等价特征 |
| `crisis` / `high_stimulus` | 不调用图片模型，返回 `IMAGE_GENERATION_BLOCKED`，保留当前已审核头像 |

Prompt 不能替代图片安全检查、医生审核和会话授权。

## 4. v1.1 映射原则

### 4.1 固定渲染顺序

1. 声音性别与年龄感：决定基础结构；
2. 情绪：决定眉、眼、唇的局部状态，最多两组可见面部信号；
3. 音调、语速、音色：决定比例、质感、轮廓与微张力；
4. 强大感、恶意程度：仅调节人物占比、明暗和距离感；
5. 安全转换：把不安全效果替换为低刺激等价信号，不清空字段含义；
6. 医生视觉覆盖：仅覆盖对应维度，仍受所有安全规则约束。

情绪不能被光线或音色覆盖；语速不能改变情绪方向；强大感与恶意程度不能造成黑衣、低机位、压迫姿态、威胁凝视或强阴影。

### 4.2 基础结构

- 男声：自然略有结构感的下颌与眉形、常规短发；不夸张性别特征。
- 女声：自然柔和的下颌与眉眼曲线、常规短发或中长发；不添加妆容与饰品。
- 不确定/混合：中性脸部表达，不强化性别化骨骼、发型或色调。
- 儿童：短宽幼态脸、五官集中、短鼻梁、圆润下颌、无细纹；始终温和非威胁。
- 青少年：略拉长脸型、舒展五官、无明显细纹、适中轮廓。
- 青年：均衡成年比例、自然平整皮肤、适中立体感。
- 中年：轻微眼角纹、法令纹与自然松弛，不夸大衰老。
- 老年：自然鱼尾纹、法令纹、眼袋和可见灰白眉发；始终暖中性柔光。

### 4.3 音调、语速、音色

| 输入 | 安全且可见的映射 |
|---|---|
| 音调 1–5 | 从宽厚、圆钝、舒展五官逐级过渡到轻度纤细狭长、紧凑自然眉眼和浅亮细节；高音不生成尖脸或凶狠骨相。 |
| 语速 1–5 | 从舒展低张力逐级过渡到轻度眉间聚焦与自然闭唇；只改变微张力，不能覆盖情绪。 |
| 沙哑粗糙 | 轻度可见哑光皮肤质感、柔化高光。 |
| 清亮通透 | 细腻皮肤、均匀漫射柔光、干净小范围高光。 |
| 尖锐刺耳 | 小巧五官、轻微清晰轮廓、浅冷中性细节，不产生锐利感。 |
| 低沉浑厚 | 宽厚饱满脸型、自然软组织体积、低饱和中性柔光。 |
| 气声虚弱 | 较小但清晰的主体比例、柔和边缘和低对比光，不失焦或病态化。 |
| 鼻音偏重 | 自然略饱满软组织、柔和鼻翼光影、温润质感。 |
| 口齿含糊 | 柔和面部边缘与明暗过渡，五官仍可辨。 |
| 厚重口音 | 略宽厚脸型、柔和层次光影、无高对比暗角。 |
| 纤细轻柔 | 小巧轻薄五官、较弱体积感与浅亮柔光，不幼态化或脆弱化。 |

### 4.4 情绪

- 愤怒：轻微眉心收拢、自然闭唇、下颌轻收；禁止怒视、咬牙、青筋和明显敌意。
- 冷漠：平缓面部、轻微放空但自然的视线、放松肌肉；禁止空洞眼神。
- 嘲讽：可辨识但极浅的单侧嘴角变化、平淡眼神；禁止坏笑、露齿和蔑视。
- 悲伤：眉眼小幅柔和下垂、放松面部；禁止眼泪、红肿和崩溃。
- 恐惧：内眉轻微上提、自然睁眼和轻度柔和紧张；禁止惊悚瞪眼、惨白和冷汗。
- 命令式：眼平、头颈端正、自然闭唇和稳定姿态；禁止压迫凝视和居高临下。

愤怒与命令式同时出现时合并为一组“克制的愤怒/命令式”信号；不得出现任何笑容。三项情绪同时填写时，最多保留两组局部面部信号，其余仅作为相容的轻度气质，不能叠加刺激效果。

### 4.5 强大感、恶意程度与安全等价

- 强大感 1–5 对应约 45%、55%、65%、72%、78% 的主体占比；始终眼平、非压迫。
- 恶意 1–5 从暖中性松弛感，逐级过渡到明亮低饱和中性画面、克制警觉的自然眼神与平直闭唇。
- 高恶意不得使用黑衣、凝视、阴影眼窝、冷暗光、尖锐骨相或威胁性姿态。
- 儿童：强大感最高按 2 档、恶意程度最高按 1 档；仍保留相应的温和表情信号。
- 老年且恶意 ≥4：恶意最多按 2 档执行，保留明亮低饱和冷中性与轻微警觉眼神，不使用冷暗光或攻击性表情。
- 强大感与恶意均 ≥4：两者最多按 3 档执行，保留稳定饱满但非压迫的胸像比例与克制闭唇，提亮背景并最小化阴影。

## 5. System Prompt

```text
Prompt template version: voice-to-appearance-v1.1

你是“幻听患者个性化 Avatar 系统”的受控人像生成提示词执行器。根据医生录入的匿名 Q1–Q8 结构化声音特征生成一名虚构、非身份化、低刺激的人类写实头像。

输出一张 1024×1024 的 1:1 PNG；单人、写实胸像、正面或不超过 15° 轻微侧脸、眼平居中。使用浅暖灰或医疗纸白纯色背景、柔和均匀漫射光、米白/浅灰/浅雾蓝纯色上衣；无首饰、文字、logo、水印。不得把声音映射为种族、具体身份、职业、疾病、人格结论或患者本人长相。

调用方会给出“视觉蓝图”。按基础结构 → 面部信号 → 声音质感 → 画面调制 → 安全保留信号的顺序渲染。每个已提供字段至少保留一个可见但克制的视觉信号；不得用中性化抹去安全转换后的信号。

年龄和声音性别只决定基础结构；情绪只决定眉、眼、唇的局部状态；音调和音色决定比例、质感与轮廓；语速只调节微张力，不能改写情绪方向；强大感与恶意感只调节主体比例、明暗和距离感，不能制造威胁性姿态、黑色服装或压迫构图。

儿童、老年、敏感风险及高冲突输入必须执行蓝图中的安全保留信号：以低刺激等价信号替代风险效果，而非删除字段含义。愤怒或命令式时不得出现任何笑容。

绝不生成真实人物复刻、身份信息、医疗诊断暗示、武器、伤口、血迹、自伤或攻击动作、暴力场景、恶魔/鬼怪、尖牙尖角、恐怖鬼脸、夸张瞪眼、青筋、面部扭曲、纹身、黑暗牢笼/废墟/阴暗小巷、多人、文字或水印。只生成图片，不输出解释文字。
```

## 6. 动态 User Prompt 模板

调用方先校验输入、执行风险门禁和安全上限，再生成视觉蓝图并填充以下模板：

```text
请执行一次受控的人像生成，只生成图片，不输出解释文字。

## 本次结构化输入

{{q1_q8_input_json}}

## 视觉蓝图

- 基础结构：{{base_structure}}
- 面部信号（最多两组局部可见信号）：{{face_signals}}
- 声音质感：{{voice_texture}}
- 画面调制：{{scene_modulation}}
- 安全保留信号：{{safety_retention}}
- 负向约束：{{negative_constraints}}

## 执行参数与覆盖

- 有效强大感：{{effective_power_level}} 档；有效恶意感：{{effective_malice_level}} 档。
- 医生确认的视觉覆盖：{{doctor_overrides_json}}
- 风险等级：{{risk_level}}；生成模式：{{generation_mode}}。
- 先严格满足固定肖像契约，再按视觉蓝图渲染。每项已提供的表单特征都要保留至少一个可见、克制且安全的信号；禁止用中性化抹去这些信号。
```

变量必须 JSON 转义；未填写的可选字段用 `null`；不得把患者原文或身份信息插入 Prompt。

## 7. 医生视觉覆盖与生成模式

允许覆盖：`gender_expression`、`age_expression`、`face_shape`、`skin_texture`、`facial_expression`、`gaze`、`lighting`、`composition`、`background`。

覆盖不得要求真实人物、身份复刻、武器、伤口、血迹、暴力、恐怖元素、阴暗场景或突破儿童/老年/敏感风险上限。

- `initial`：首次按完整 Q1–Q8 生成。
- `same_features_regenerate`：复用已确认的有效视觉特征，仅更换随机种子。
- `feature_update`：使用更新后 Q1–Q8 与医生覆盖，创建新版本。

## 8. 统一负向约束

黑色或深色上衣、首饰、复杂场景、低机位、俯视或仰视压迫构图、强阴影、暗角、阴影眼窝、冷暗光、夸张皱眉、露齿、怒视、咬牙、愤怒或命令式与笑容并存、哭泣、病态化、恐怖化眼神、身份识别线索、文字、logo、水印、多人、真实人物复刻、暴力或恐怖元素。

## 9. 验收与回归

1. 先用 B01、S06、S08、I04、E01、E02 作为 v1.1 门槛集。
2. 每条生成 3 次，固定模型、尺寸、风格及其余推理参数；供应商支持时记录并固定种子。
3. 每张图片均须无安全违例，视觉分与特征分的中位数均达到 4，才进入全量 24 条回归。
4. 全量回归重点复测 R01、R03、R05、R06：允许人物保持非身份化变化，但年龄感、情绪、画幅、服装风格与映射特征不得漂移。
5. 未达 4 时，在测试数据表的“未达4主因”多选标签中记录：构图质量、年龄/性别、音调、语速、音色、情绪、强度、恶意、安全边界、稳定性。
