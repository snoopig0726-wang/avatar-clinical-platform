## 3. 当前生成与授权链路

1. 医生创建去标识化病例和一次性邀请码；
2. 患者兑换邀请码，医生确认当面知情同意并启动监督会话；
3. 医生逐项录入 Q1–Q8；
4. 系统执行确定性声音到视觉特征映射；
5. 医生检查并确认最终视觉特征；
6. 医生在访谈页或病例页发起 GPT Image 2 生图；
7. 患者页面进入“医生正在生成图像，请稍候”的过程状态；
8. 后端向 GPT Image 2 提交固定低刺激肖像 Prompt；
9. 返回图片必须通过 PNG 签名、文件体积和 1024×1024 尺寸检查；
10. 图片继续经过安全检查，未通过时不得进入医生审核或患者授权；
11. 医生审核图片，通过后选择是否授权当前患者会话查看；
12. 患者只能查看当前会话中经过医生审核并明确授权的版本；
13. 患者提出调整后，文本先经过 `RISK-V1.4` 多语言风险检查；
14. 医生可以直接接受、可选重写后重新映射，或填写理由拒绝；
15. 只有医生确认后的受控指令可以进入下一轮 GPT Image 2 生图。

患者原始调整文本不会直接发送给 GPT Image 2。医生重写文本也必须重新经过风险检查，
最终只使用后端映射得到的低刺激受控指令。

## 4. 图片安全边界

当前图像安全链路包含以下层级：

1. GPT Image 2 请求使用 `moderation=auto`；
2. Prompt 固定禁止真实人物复刻、身份信息、医疗诊断暗示、武器、伤口、血迹、自伤、
   暴力、恐怖化、多人、文字和水印；
3. 后端校验 PNG 文件签名、体积、格式和 1024×1024 尺寸；
4. 独立语义图片复检适配器负责二次判定，并与生图 Provider 解耦；
5. 任何检查失败都必须保留原已授权版本，不向患者展示失败候选图；
6. 图片只有在安全检查与医生人工审核均通过后才能授权给患者。

独立语义图片复检是 GPT Image 2 之后的附加安全层，不是图像生成替代方案，也不改变
当前图像由 GPT Image 2 生成这一事实。

## 5. 多语言风险规则

当前 `RISK-V1.4` 在患者提交和医生重写两个阶段执行，支持：

- 简体中文；
- 繁体中文标准化后判定；
- 英文风险表达映射后判定；
- 刀具、锐器或创口与血液、伤害语义的跨标点、跨空格组合判定；
- 自杀、轻生、死亡愿望、希望不再醒来等简体、繁体和英文委婉表达；
- PII 格式检查；
- 危机、自伤、血腥、武器、暴力、恐怖化、身份复刻、歧视、未成年人伤害、
  妄想强化、色情和极端主义等类别；
- 排除“不要、移除、避免、不显示”等安全否定语境；
- 风险命中时不创建可生成请求，不保存风险原文，不消耗患者调整额度。
