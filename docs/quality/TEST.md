# 测试与验收矩阵

- 所属产品：幻听患者个性化 Avatar 生成系统
- 关联 PRD：https://ycnhe29l1vtr.feishu.cn/docx/JAY0d7gkgoVAAjxa8vVcoQK1nKc
- 文档版本：V1.2
- 文档状态：正式版
- 来源：PRD V3.0 审查修订 +《副本验收标准.docx》全链路重构

## 0. 测试约定

### 0.1 验收对象

V1 只验收三类角色：医生、受邀患者、系统管理员。患者不注册、不登录；系统不提供额外工作人员角色、入口、路由或 API。

### 0.2 优先级

| 优先级 | 定义 | 通过要求 |
|-|-|-|
| P0 | 安全、权限、数据删除、核心流程阻断项 | 任一失败，V1 不得通过 |
| P1 | 主流程完整性、稳定性和重要异常 | 必须全部通过或有书面豁免 |
| P2 | 可用性、兼容性和体验增强项 | 可列入后续版本，但不能影响 P0/P1 |

### 0.3 用例记录格式

每条用例至少记录：用例 ID、优先级、前置条件、执行步骤、预期结果、实际结果、证据链接、执行人、执行时间和状态（Not Run / Pass / Fail / Blocked）。

P0 用例必须保留可复核证据：页面截图、API 请求/响应日志、数据库查询结果、审计记录、对象存储检查结果或删除任务执行记录。

### 0.4 测试环境

- 浏览器：Chrome、Edge、Safari 最新两个大版本；PC 端优先。
- 测试数据：使用去标识化病例编号，不使用真实患者身份信息。
- 模型：业务联调使用 OpenAI `gpt-image-2`；自动化测试使用不产生真实费用的可控测试替身覆盖成功、超时、拒绝、异常响应和输出安全失败。
- 时间：可注入测试时钟，用于验证邀请码过期、会话结束和 30 天删除任务。
- 外部依赖：风险服务、图像服务、对象存储和删除任务在自动化测试中可替换为可控测试替身；测试结果不得被表述为真实 GPT Image 2 画质、耗时或费用验收。

| NFR-009 | P0 | 删除任务积压 | 删除任务超过阈值触发告警；任务可重试并最终产生可审计结果 |

## 11. 上线验收闸门

以下任一项失败，V1 不得通过：

- 患者可以注册、登录、进入病例列表或访问其他病例；
- 患者可以查看未审核、未授权或历史版本 Avatar；
- 患者可以直接生成、回退、替换、删除或下载 Avatar；
- 患者调整可以绕过风险校验、医生审核、二次确认或输出安全检查；
- 患者超过 3 次调整，或出现并行 pending 调整；
- 安全暂停后患者仍可访问，或医生结束会话后旧页面仍可访问；
- 医生回退后旧授权未撤销，或未重新审核即可展示；
- 30 天后仍能恢复或读取已删除的病例、图片、备份或会话凭证；
- 管理员可以查看病例原文、访谈答案、患者调整原文或 Avatar 图片；
- 模型服务不可用时系统绕过风险判断或安全审核；
- 审计日志包含患者原文、图片、Prompt、密码、验证码或邀请码明文；
- 存在额外工作人员旧入口、路由、权限或 API；
- 任一 P0 用例失败，或 P0 用例缺少可复核证据。

5. 测试报告中不存在未关闭的 P0 缺陷。
