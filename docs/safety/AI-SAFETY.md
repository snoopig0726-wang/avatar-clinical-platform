# AI 安全与风险拦截规则

- 所属产品：幻听患者个性化 Avatar 生成系统
- 规则版本：RISK-V1.3
- 文档版本：V1.3
- 文档状态：Current
- 最近更新：2026-07-30
- 用途：定义后端多语言风险校验、拦截动作、用户提示和 GPT Image 2 调用边界

## 1. 适用范围

### 1.1 首轮 Q1–Q8

首轮 Q1–Q8 只接受结构化选项，执行字段、必填、枚举、长度、状态和权限校验，不执行
患者自由文本调整规则，也不产生 `normal/sensitive/crisis/high_stimulus` 患者内容分类。

首轮生图安全由确定性低刺激映射、医生确认、固定 Prompt 禁止项、GPT Image 2
`moderation=auto`、图片安全检查和医生人工审核共同保证。

### 1.2 患者调整文本

患者在已授权 Avatar 页面提交调整文本时，后端必须先执行本规则。前端不维护关键词库，
也不能自行决定是否放行。

只有风险检查通过，系统才创建“等待医生审核”的调整请求。患者原文加密保存，仅当前
监督医生可见，不直接发送给 GPT Image 2。

### 1.3 医生重写文本

医生调整是可选操作。医生选择重写患者描述时，重写后的文本必须再次执行同一版本的
多语言风险检查。只有检查通过，后端才重新映射低刺激受控指令。

医生点击直接接受时，后端也必须在审核时重新检查患者原文，防止规则升级后旧请求绕过
当前安全策略。

## 2. 支持语言与归一化

风险引擎统一执行：

- Unicode NFKC 归一化；
- 英文字母大小写折叠；
- 受控词表范围内的繁体字转简体字；
- 标点、空格和兼容字符归一化；
- 英文风险语义标记映射；
- 手机号、身份证号、银行卡号和邮箱格式检查。

同一安全规则适用于简体中文、繁体中文和英文输入。界面语言不影响后端判定。

## 3. 后端判定结果

| 结果 | 判定条件 | 后端动作 | 患者可见提示 |
|-|-|-|-|
| `allow` | 未命中启用规则 | 创建待医生审核请求；不调用图像模型 | 已提交，等待医生审核 |
| `blocked` | 直接命中或上下文命中 | 不创建请求；不保存风险原文；不调用模型 | 内容存在风险，请修改后重试。 |
| `service_unavailable` | 规则读取、依赖或执行异常 | 失败关闭；不创建请求；不调用模型 | 风险校验暂时不可用，请稍后重试。 |
| `session_invalid` | 会话过期、结束、暂停或无权访问 | 拒绝请求；不调用模型 | 会话已结束或暂时不可用。 |

具体命中词、完整规则内容、内部 Prompt 和供应商错误不返回患者。

## 4. 规则匹配原则

- `direct`：命中即拦截，不依赖额外上下文；
- `context`：风险词与动作、视觉或强化条件共同出现时拦截；
- `pii`：身份词或格式命中即拦截；
- “没有、不要、不包含、禁止、避免、去掉、移除、排除、不显示”仅能排除上下文规则，
  不能覆盖自伤、危机、色情或其他直接高风险表达；
- 风险规则读取失败或无法执行时失败关闭；
- 规则只用于阻断风险，不用于诊断、人格判断或确认幻听内容真实存在；
- 审计只记录规则版本和脱敏规则编号，不记录患者风险原文。

blood”“blood on the blade”和“blood-smeared razor”均会被拦截。中文单字“血”
不会被无条件视为直接命中，避免误拦截“脸色更有血色，看起来健康一些”等非伤害性描述；
但它与刀具、锐器或伤口词同时出现时会触发上下文规则。

## 6. 用户提示

| 场景 | 固定提示 |
|-|-|
| 一般风险 | 内容存在风险，请修改后重试。 |
| 身份信息 | 请勿输入姓名、手机号、身份证号、邮箱或其他身份信息。 |
| 危机表达 | 请先暂停操作，并联系现场医生获得支持。 |
| 规则服务不可用 | 风险校验暂时不可用，请稍后重试。 |

风险弹窗关闭后，前端保留输入内容，允许用户修改。风险拦截不消耗当前会话的调整额度。

## 7. GPT Image 2 调用边界

患者调整的生成链路为：

`风险通过 → 医生直接接受或可选重写 → 审核时再次检查 → 受控映射 → 医生发起生成 → GPT Image 2 → 图片安全检查 → 医生审核 → 患者授权`

GPT Image 2 只接收：

- 当前医生确认的视觉特征；
- 冻结的 Q1–Q8 来源快照；
- 医生批准后由后端生成的受控调整指令；
- 固定低刺激肖像契约与永久禁止项。

不得发送患者原始文本、医生自由文本、真实身份信息、风险命中原因或审计内容。

## 8. 审计与留存

- 风险拦截不持久化患者风险原文；
- 风险通过后的患者原文和医生重写文本分别加密保存；
- 只有当前监督医生可以在处理调整期间读取患者原文；
- 审计记录规则版本、脱敏规则编号、操作者、时间、状态和处理结果；
- 不记录风险命中片段、完整 Prompt、图片内容或供应商内部命中原因；
- 病例到期删除时清理调整文本、风险数据和所有关联业务数据。

## 9. 规则变更

规则变更必须升级规则版本、更新本文件和黑盒测试场景。后端是唯一判定源，前端不得
复制、放宽或绕过风险规则。
