# AI 安全与风险拦截规则

- 所属产品：幻听患者个性化 Avatar 生成系统
- 关联 PRD：https://ycnhe29l1vtr.feishu.cn/docx/JAY0d7gkgoVAAjxa8vVcoQK1nKc
- 规则版本：RISK-V1.0
- 文档版本：V1.1
- 文档状态：Draft
- 用途：定义后端风险校验、拦截动作、用户提示和模型调用边界

## 1. 规则适用范围

### 1.1 首轮结构化表单

首轮 Q1–Q8 声音特征表单只接受结构化选项。首次填写、保存、提取视觉特征和进入特征确认页不触发本文件的调整文本风险拦截。

首轮表单仍需执行字段格式、必填项、长度和权限校验；不得把首轮结构化字段误判为患者调整文本。

### 1.2 患者调整文本

患者在已授权 Avatar 页面提交调整文本时，后端必须先执行本文件定义的风险校验。前端不得自行维护关键词库或决定是否放行。

只有风险校验通过，文本才可以创建“待医生审核”的调整请求。风险通过不等于允许生图；患者原始文本不得直接进入图像模型。

## 2. 后端判定结果

| 结果 | 判定条件 | 后端动作 | 患者可见提示 |
|-|-|-|-|
| `allow` | 未命中规则，且未出现不确定情况 | 创建待医生审核请求；不调用图像模型 | 已提交，等待医生审核 |
| `blocked` | 直接命中、上下文命中或无法确认安全 | 不创建调整请求；不保存原文；不调用模型 | 内容存在风险，请修改后重试。 |
| `service_unavailable` | 规则服务超时、异常或无法读取规则 | 不放行；不创建调整请求；不调用模型 | 风险校验暂时不可用，请稍后重试。 |
| `session_invalid` | 会话过期、停止、暂停或无权访问 | 拒绝请求；不调用模型 | 会话已结束或暂时不可用。 |

内部命中原因、具体规则编号、风险词、Prompt 和供应商错误不得返回给患者。

## 3. 规则匹配原则

- 文本先做 Unicode 归一化、大小写归一化和空白清理，再进行匹配。
- `direct_hit` 不需要关联词，命中即拦截；排除词不能覆盖直接高风险词。
- `context_hit` 必须同时满足风险词和关联条件；满足排除条件时不触发该条规则。
- 无法判断是否安全时按 `blocked` 处理，不得默认放行。
- 规则只用于阻断风险和保护会话，不用于诊断、评估患者人格或确认幻听内容真实存在。
- 每次判定记录规则版本和脱敏规则编码，不记录患者原文或完整 Prompt。

## 5. 用户提示规则

风险提示必须使用中性、简短、可操作的文案，不展示具体命中词和内部判定依据。

| 场景 | 固定提示 |
|-|-|
| 风险拦截 | 内容存在风险，请修改后重试。 |
| 风险服务不可用 | 风险校验暂时不可用，请稍后重试。 |
| 身份信息 | 请勿输入姓名、手机号、身份证号、邮箱或其他身份信息。 |
| 危机表达 | 请先暂停操作，并联系现场医生获得支持。 |

风险拦截弹窗关闭后，前端保留患者输入内容，允许修改后重新提交。

## 6. 模型调用边界

风险通过后只创建待医生审核请求，不能直接调用图像模型。

二次生成必须经过：

`风险通过 → 医生原样通过或编辑后通过 → 医生确认替换 → 受控指令转换 → 保留形象编辑 → 图片安全检查 → 医生复核 → 患者重新授权`

图像模型只能接收：

- 当前已审核 Avatar 参考图；
- 已锁定的视觉特征；
- 医生批准后的受控调整指令；
- 固定低刺激约束和禁止元素约束。

不得发送患者原始文本、真实身份信息、内部命中原因或完整审计信息。

## 7. 审计和留存边界

- 风险拦截失败时不持久化患者原文。
- 风险通过后的原文仅在当前会话和当前监督医生审核期间可见。
- 审计只记录规则版本、脱敏事件、操作者、时间、状态和处理结果。
- 不记录患者原文、敏感词命中片段、内部 Prompt 或供应商内部命中原因。
- 会话结束或达到既定保存期限后，按 PRD 的数据清理策略删除调整文本和关联数据。

## 8. 规则变更

规则变更必须更新规则版本，并同步更新飞书 PRD 第七部分的规则摘要和 `avatar-v1-docs/TEST.md` 的黑盒验收场景。开发实现不得在前端复制或绕过本文件定义的后端规则。
